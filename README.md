# Arduino Remote — ریموت کنترل آردوینو 🎛️

اپ موبایل برای کنترل دستگاه‌های آردوینو (مثل HC-05) با **کنترل‌های کاملاً سفارشی**:
هر کلید، لغزنده یا دستوری که بخواهی را خودت می‌سازی، نام و آیکن و رنگ و دستورش را
تعریف می‌کنی و در قالب «دستگاه» (پروفایل) گروه‌بندی می‌کنی.

پشته‌ی فنی (همان ترکیبی که برای انجام جواب داد):

| لایه | انتخاب |
|---|---|
| زبان | **TypeScript** (strict، بدون `any` بی‌دلیل) |
| UI | **React 18** + Vite 5 |
| پوسته‌ی اندروید | **Capacitor 6** (همان مسیر انجام: JDK 17 + Android SDK 34) |
| بلوتوث کلاسیک | `cordova-plugin-bluetooth-serial` (SPP — برای HC-05) |
| تست | unit با `node --experimental-strip-types` + تست مرورگری CDP |

## چرا بلوتوث فقط در APK کار می‌کند؟

مرورگرها **بلوتوث کلاسیک (SPP)** را در اختیار صفحه‌وب نمی‌گذارند؛ فقط BLE که HC-05
ندارد. برای همین اپ دو نسخه دارد:

- **وب (PWA)**: همه‌ی منطق و UI کار می‌کند؛ اتصال با «شبیه‌ساز»، «وب‌سوکت» یا «سریال USB».
- **APK اندروید**: همان کد + پل بلوتوث → کنترل مستقیم HC-05 با گوشی.

## چهار نوع اتصال

| نوع | کجا کار می‌کند | کاربرد |
|---|---|---|
| 🎮 شبیه‌ساز | همه‌جا | یادگیری و تست بدون سخت‌افزار — هر دستور برمی‌گردد |
| 📶 بلوتوث کلاسیک | فقط APK | اتصال مستقیم به HC-05/HC-06 |
| 🌐 وب‌سوکت | وب + APK | پل دلخواه (رایانه با دانگل BT، ESP، سرور) |
| 🔌 سریال USB | کروم رومیزی | تست با کابل USB و سرعت ۹۶۰۰ |

## کنترل‌ها

- **کلید روشن/خاموش** — دو دستور جدا (on/off) + وضعیت ماندگار
- **کلید لحظه‌ای** — دستور هنگام فشردن + دستور اختیاری هنگام رها کردن
- **لغزنده** — نمایش و خروجی مستقل (مثلاً ۰-۱۰۰ نمایش ← ۰-۲۵۵ خروجی)، الگوی
  `V{v}`، حالت «فقط هنگام رها کردن»
- **متن دلخواه** — جعبه‌ی ارسال آزاد

همه‌ی کنترل‌ها: نام، آیکن، رنگ، کاراکتر انتهایی (بدون / `\n` / `\r\n`)، ویرایش،
جابه‌جایی ترتیب، حذف دومرحله‌ای.

## دستورات

```bash
npm install          # نصب وابستگی‌ها
npm run dev          # توسعه با HMR (vite)
npm run build        # typecheck سخت‌گیرانه + بیلد production
npm test             # تست‌های واحد (منطق + انتقال سوکت واقعی)
npm run preview      # پیش‌نمایش بیلد روی http://127.0.0.1:4173
```

### ساخت APK اندروید

```bash
npx cap add android              # فقط بار اول
npm run android:sync             # بیلد وب + cap sync + پچ mirrorهای maven
npm run android:release          # gradle assembleRelease → امضا → verify → چک محتوا
```

خروجی: `releases/ArduinoRemote-v1.0.0.apk`

پیش‌نیازها (روی همین ماشین نصب‌اند):

```
JAVA_HOME    = C:/Users/My Sweet/toolchain/jdk17.0.20_10
ANDROID_HOME = C:/Users/My Sweet/android-sdk
```

`release.keystore` بار اول خودکار ساخته می‌شود (alias: `arduremote`).

## ساختار پروژه

```
src/
  lib/
    types.ts          انواع داده (کنترل‌ها، پروفایل، اتصال)
    events.ts         رویدادساز تایپ‌شده
    commands.ts       ترجمه‌ی رویداد UI → دستور متنی (خالص، قابل تست)
    storage.ts        ماندگاری + اعتبارسنجی/ترمیم داده
    store.ts          فروشگاه وضعیت (الگوی useSyncExternalStore)
    connection.ts     مدیر اتصال + کارخانه‌ی Transportها
    runner.ts         ارسال دستور + ثبت در کنسول
    log.ts            کنسول رویداد
    transports/
      transport.ts    قرارداد پایه
      demo.ts         شبیه‌ساز
      websocket.ts    پل سوکت (در node هم تست می‌شود)
      webserial.ts    USB رومیزی
      bluetooth.ts    پل Cordova برای HC-05
  ui/                 کامپوننت‌های React
tests/
  unit.mjs            تست‌های واحد (بدون mock شبکه)
  ws-echo.mjs         سرور اکوی WebSocket دست‌ساز برای تست واقعی
scripts/
  gen-icons.mjs       تولید PNG آیکون‌ها بدون وابستگی
  android-release.mjs خط لوله‌ی APK
  patch-capacitor-mirrors.js  پچ mirror (از انجام — برای شبکه‌های مسدود)
```

## تست‌ها چه چیزی را پوشش می‌دهند

- `commands`: گردش اعداد، بازه‌ی معکوس، clamp، الگو، suffix، رویداد غلط
- `storage`: ترمیم داده‌ی خراب، رد کنترل بی‌معنی، رفت و برگشت JSON
- `store`: CRUD کنترل/پروفایل + قرارداد snapshot برای React
- انتقال‌ها با **شبکه‌ی واقعی**: سرور اکوی WebSocket دست‌ساز (handshake + فریم
  RFC6455) → اتصال، اکو، قطع، آدرس غلط، پورت بسته
- مسیرهای خطا: بلوتوث بدون پل (پیام APK)، سریال بدون Web Serial

## عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| در وب گزینه‌ی بلوتوث وصل نمی‌شود | طبیعی است — مرورگر SPP ندارد. از APK یا شبیه‌ساز استفاده کن |
| APK مجوز بلوتوث نمی‌دهد | در تنظیمات اندروید → برنامه‌ها → Arduino Remote → مجوزها را بده (اندروید ۱۲+ دو مجوز BLUETOOTH_CONNECT/SCAN می‌خواهد که اپ خودش درخواست می‌کند) |
| اتصال وب‌سوکت قطع می‌شود | آدرس باید `ws://` باشد و پل همزمان بالا باشد |
| کد قدیمی بعد از تغییر دیده نمی‌شود | `npm run build` را دوباره بزن؛ در APK هم `android:sync` |
